# Interactive checklist

A tick-off list with a sticky progress meter. At 10 ticks a navy box appears with a Compare My Funding CTA.

- **Where it goes:** in place of a static document or readiness checklist.
- **Text it needs:** a title and one-line description per item. Update "of 14" in the markup and the thresholds in the JavaScript if the item count changes.
- **JavaScript:** yes.
- **Compliance:** the completion message says approval is never guaranteed; keep that.
- **Known limits:** only the first checklist on a page works; the item count is hardcoded.
