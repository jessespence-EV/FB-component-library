# Funding stack builder

Four sliders build a stacked bar of funding sources against a "total needed" marker, with a live status: balanced, funding gap or over-raised.

- **Where it goes:** alongside a worked example in the post.
- **Text it needs:** the total in `data-uses`, the uses breakdown in the header, and a label, min, max, step and starting value for each slider. Use the article's own (fictional) figures.
- **JavaScript:** yes.
- **Compliance:** keep the "illustrative, fictional assumptions" note.
- **Known limits:** fixed input IDs (`fbs1` to `fbs4`) mean only one per page; one legend colour is hardcoded.
