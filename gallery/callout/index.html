Callouts

Warning and tip notes that highlight a key point next to the text.

HTML and CSS only

Live demo

How to use it

Copy HTML gives you the markup and its script, ready for a WordPress Custom HTML block. Swap the demo text for the post's own. Copy CSS gives the shared base styles plus this component's styles. If fb.css is already in Additional CSS, you only need the HTML.

A highlighted note with an icon. Two variants: warn (amber, "!") and tip (coral, "i").

  • Where it goes: next to the paragraph it qualifies.
  • Text it needs: a short bold title and one or two sentences.
  • JavaScript: none.
  • Known limits: the amber and pale backgrounds are hardcoded rather than tokens.

Code

HTML (paste into a Custom HTML block)
<!-- Warning callout. Place after the senior debt section, or under the worked example. -->
<div class="fb-block fb-callout warn">
  <div class="fb-ci-ico">!</div>
  <div><b class="fb-ct">Balanced is not the same as affordable</b><p>A sources-and-uses schedule that adds up does not prove the repayment profile works. Always model monthly cash flow across every funding layer.</p></div>
</div>

<!-- Tip callout. Place under the Readiness Checklist heading or in "Documents to Prepare". -->
<div class="fb-block fb-callout tip">
  <div class="fb-ci-ico">i</div>
  <div><b class="fb-ct">Keep your assumptions consistent</b><p>Use the same numbers across the business plan, forecast and funding request. Differences between documents can delay lender assessment.</p></div>
</div>
