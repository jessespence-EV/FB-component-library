Match-up grid

Pairs what a business has with the funding types that may suit it.

HTML and CSS only

Live demo

How to use it

Copy HTML gives you the markup and its script, ready for a WordPress Custom HTML block. Swap the demo text for the post's own. Copy CSS gives the shared base styles plus this component's styles. If fb.css is already in Additional CSS, you only need the HTML.

Rows pairing "what you have" on the left with "what may fund it" on the right. Stacks vertically on mobile.

  • Where it goes: in place of a bullet list that maps assets or needs to funding types.
  • Text it needs: per row, a short label, a small sub-label and a one-line answer. Link answers to fundingbay.co.uk product pages where they exist.
  • JavaScript: none.
