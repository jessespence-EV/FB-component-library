Key takeaways

The post's main points as a ticked list, with a four-item stat strip.

HTML and CSS only

Live demo

How to use it

Copy HTML gives you the markup and its script, ready for a WordPress Custom HTML block. Swap the demo text for the post's own. Copy CSS gives the shared base styles plus this component's styles. If fb.css is already in Additional CSS, you only need the HTML.

A pale box with a coral left border, a ticked list of the post's main points and a four-item stat strip.

  • Where it goes: directly under the intro paragraph.
  • Text it needs: three to five takeaways (bold lead-in, then one sentence) and four stats. Only use figures from the article or the approved facts (200+ lenders, soft credit check).
  • JavaScript: none.
  • Known limits: the demo stats ("7 routes", "14 point checklist") are specific to the acquisition finance post.

Code

HTML (paste into a Custom HTML block)
<!-- Place directly under the intro paragraph. -->
<div class="fb-block fb-key">
  <span class="fb-eyebrow">In short</span>
  <ul>
    <li><strong>Start with the deal, not the product.</strong> Split the price into goodwill, assets, property, fees, working capital and a cash buffer. Each part may need a different funding source.</li>
    <li><strong>Seven routes are available:</strong> senior debt, asset-backed lending, asset finance, vendor finance, equity, MBO/MBI funding and blended structures.</li>
    <li><strong>Match the money to what you are buying.</strong> Goodwill, debtors, equipment and property each point to a different type of funding.</li>
    <li><strong>Stress-test before you commit.</strong> A smaller debt burden can protect cash flow during integration.</li>
  </ul>
  <div class="fb-stats">
    <div><b>7</b><span>funding routes compared</span></div>
    <div><b>14</b><span>point readiness checklist</span></div>
    <div><b>200+</b><span>UK lenders on our panel</span></div>
    <div><b>Soft</b><span>credit check to compare</span></div>
  </div>
</div>
