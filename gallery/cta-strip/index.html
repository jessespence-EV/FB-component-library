CTA strip

A navy mid-article strip with a heading, one line and a button.

HTML and CSS only

Live demo

How to use it

Copy HTML gives you the markup and its script, ready for a WordPress Custom HTML block. Swap the demo text for the post's own. Copy CSS gives the shared base styles plus this component's styles. If fb.css is already in Additional CSS, you only need the HTML.

A navy gradient strip with a short heading, one line of text and a button.

  • Where it goes: mid-article, between major sections.
  • Text it needs: heading, one supporting line, button label and link (Get in touch or Compare My Funding).
  • JavaScript: none.

Code

HTML (paste into a Custom HTML block)
<!-- Mid-article CTA strip. Place after "Compare UK Acquisition Funding Routes" section (before "Match the Finance"). -->
<div class="fb-block fb-strip">
  <div>
    <h4>Want a second opinion on your funding mix?</h4>
    <p>Talk through your target, timetable and buyer profile with a broker.</p>
  </div>
  <a class="fb-btn" href="https://fundingbay.co.uk/get-in-touch/">Speak to Funding Bay →</a>
</div>
