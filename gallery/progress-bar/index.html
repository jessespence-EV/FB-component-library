Reading progress bar

A thin coral bar along the top of the screen that fills as the reader scrolls.

InteractiveOnce per post

Live demo

Scroll inside the demo to see it in action.

How to use it

Copy HTML gives you the markup and its script, ready for a WordPress Custom HTML block. Swap the demo text for the post's own. Copy CSS gives the shared base styles plus this component's styles. If fb.css is already in Additional CSS, you only need the HTML.

A thin coral bar fixed to the top of the screen that fills as the reader scrolls.

  • Where it goes: once per post, anywhere (the top is fine).
  • Text it needs: none.
  • JavaScript: yes. Updates the bar width on scroll.
  • Known limits: uses the ID fbProgress, so only one per page (by design).

Code

HTML (paste into a Custom HTML block)
<!-- Place ONCE, anywhere in the post (top is fine). Reading progress bar along the top of the screen. -->
<div class="fb-progress" id="fbProgress" aria-hidden="true"></div>
<script>
(function(){
  var bar=document.getElementById('fbProgress'); if(!bar)return;
  function on(){
    var h=document.documentElement,max=h.scrollHeight-h.clientHeight,p=max>0?(h.scrollTop||document.body.scrollTop)/max:0;
    bar.style.width=(p*100)+'%';
  }
  window.addEventListener('scroll',on,{passive:true});on();
})();
</script>
