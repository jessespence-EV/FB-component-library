Contents list

Numbered jump links to each section of the post.

HTML and CSS only

Live demo

How to use it

Copy HTML gives you the markup and its script, ready for a WordPress Custom HTML block. Swap the demo text for the post's own. Copy CSS gives the shared base styles plus this component's styles. If fb.css is already in Additional CSS, you only need the HTML.

A numbered two-column list of jump links (one column on mobile).

  • Where it goes: under the key takeaways box.
  • Text it needs: one link per H2. Each href must match an HTML anchor on that H2: in WordPress select the H2 block, open Advanced, and enter the ID without the #.
  • JavaScript: none.

Code

HTML (paste into a Custom HTML block)
<!-- Place under the key takeaways box. Each link needs an "HTML anchor" on the matching H2:
     select the H2 block > Advanced > HTML anchor, and enter the ID shown in the href (without the #). -->
<nav class="fb-block fb-toc" aria-label="Contents">
  <span class="fb-eyebrow">Jump to a section</span>
  <ol>
    <li><a href="#start-with-the-deal">Start with the deal, not the finance product</a></li>
    <li><a href="#acquisition-vs-business-loan">Acquisition finance vs an ordinary business loan</a></li>
    <li><a href="#funding-routes">Compare UK acquisition funding routes</a></li>
    <li><a href="#match-the-finance">Match the finance to the target assets</a></li>
    <li><a href="#what-lenders-assess">What lenders will assess</a></li>
    <li><a href="#readiness-checklist">Your acquisition readiness checklist</a></li>

  </ol>
</nav>
