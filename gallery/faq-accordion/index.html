FAQ accordion

Expandable questions with matching FAQ schema for Google rich results.

HTML and CSS only

Live demo

How to use it

Copy HTML gives you the markup and its script, ready for a WordPress Custom HTML block. Swap the demo text for the post's own. Copy CSS gives the shared base styles plus this component's styles. If fb.css is already in Additional CSS, you only need the HTML.

Expandable questions built on native <details>, so no JavaScript is needed. Includes FAQPage structured data for Google rich results.

  • Where it goes: the FAQ section at the end of the post.
  • Text it needs: question and answer pairs. The visible text and the JSON-LD block must match word for word.
  • JavaScript: none (the <script type="application/ld+json"> is data, not code).

Code

HTML (paste into a Custom HTML block)
<!-- Replaces the four static FAQ boxes. Native <details>, so no JavaScript needed. Includes FAQ schema for Google rich results.
     Keep the visible text and the JSON-LD identical. -->
<div class="fb-block fb-faq">
  <details>
    <summary>Can I finance a business acquisition without a proven trading history?</summary>
    <p>It can be possible where the target has established trading performance and the management team has relevant experience. Expect lenders to examine your contribution, forecasts, security and the target's ability to service debt.</p>
  </details>
  <details>
    <summary>Can acquisition finance cover transaction fees as well as the purchase price?</summary>
    <p>Some facilities can include approved transaction costs, subject to lender criteria and affordability. Identify legal, valuation and advisory fees separately, then confirm which costs each funding source permits.</p>
  </details>
  <details>
    <summary>What should a new holding company provide when seeking acquisition finance?</summary>
    <p>Provide its ownership structure, constitutional documents, directors and source of buyer funds. The lender will also need target financial information and details of how cash reaches the holding company for repayments.</p>
  </details>
  <details>
    <summary>What happens if the target company has historic adverse credit?</summary>
    <p>Historic adverse credit can narrow the available routes without ending the assessment. Lenders will consider its cause, age, current status and impact on affordability, while specialist bad-credit funding criteria may differ.</p>
  </details>
</div>
