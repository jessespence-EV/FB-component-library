Sticky bottom bar

A dismissible CTA bar that slides up once the reader is 30% through the post.

InteractiveOnce per post

Live demo

Scroll inside the demo to see it in action.

How to use it

Copy HTML gives you the markup and its script, ready for a WordPress Custom HTML block. Swap the demo text for the post's own. Copy CSS gives the shared base styles plus this component's styles. If fb.css is already in Additional CSS, you only need the HTML.

A navy bar that slides up from the bottom once the reader is 30% through the post and hides near the end. The reader can dismiss it for the rest of the session.

  • Where it goes: once per post, anywhere (the top is fine).
  • Text it needs: a short bold hook and one sentence (hidden below 700px), plus the button label and link. Default CTA is Compare My Funding.
  • JavaScript: yes. Scroll position and dismiss state (stored in sessionStorage).
  • Known limits: uses IDs fbSticky and fbStickyX, so only one per page (by design). The slide-in animation does not yet respect reduced motion.

Code

HTML (paste into a Custom HTML block)
<!-- Place ONCE, anywhere in the post (top is fine). Sticky "compare lenders" bar that appears after 30% scroll. -->
<div class="fb-sticky" id="fbSticky" role="complementary" aria-label="Compare funding">
  <span><strong>Funding an acquisition?</strong> See which of 200+ UK lenders may fit. Soft credit check only.</span>
  <a class="fb-btn" href="https://comparemyfunding.co.uk/loan-offer-generator-1230001/">Compare My Funding</a>
  <button class="fb-x" id="fbStickyX" aria-label="Dismiss">×</button>
</div>
<script>
(function(){
  var st=document.getElementById('fbSticky'),x=document.getElementById('fbStickyX'); if(!st||!x)return;
  var closed=false; try{closed=sessionStorage.getItem('fbStickyX')==='1'}catch(e){}
  function on(){
    var h=document.documentElement,max=h.scrollHeight-h.clientHeight,p=max>0?(h.scrollTop||document.body.scrollTop)/max:0;
    if(!closed) st.classList.toggle('show',p>.3&&p<.97);
  }
  x.addEventListener('click',function(){closed=true;st.classList.remove('show');try{sessionStorage.setItem('fbStickyX','1')}catch(e){}});
  window.addEventListener('scroll',on,{passive:true});on();
})();
</script>
